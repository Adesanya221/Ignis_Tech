IGNIS TECH logo kit

Files
- ignis-tech-logo-white.png: transparent white logo for dark backgrounds
- ignis-tech-logo-black.png: transparent black logo for light backgrounds
- @2x versions: higher-resolution raster copies for retina screens
- ignis-tech-logo-white.svg: scalable SVG wrapper for the supplied artwork
- ignis-tech-icon.png: brain/circuit symbol, transparent
- favicon.svg, favicon-512.png, favicon-32.png, favicon-16.png, favicon.ico: browser favicon options
- reference-original.png: supplied reference image

The reference artwork is 500 x 500 pixels; the original logo artwork itself is low-resolution. The PNGs preserve its shape and lettering. For website use, choose the white logo on dark backgrounds or the black logo on light backgrounds.

HTML example:
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<img src="/ignis-tech-logo-white.png" alt="IGNIS TECH">
